# 插件目录资料

**四号船坞 · Dock No. 4** 是 DeepSeek Harness 的干船坞主题。首页显示工作区活动和待处理会话。鲸鱼娘挂件跟随会话状态，指令台可打开便签、番茄钟和专注模式，对话页支持草稿恢复和 Markdown 导出。

| 项目 | 内容 |
| --- | --- |
| npm 包 | [`dsh-afterwave-style`](https://www.npmjs.com/package/dsh-afterwave-style) |
| 分类 | `theme`（主题与外观） |
| 图标 | [`icon.png`](../icon.png)，256 × 256 PNG |
| 许可证 | [CC0 1.0 Universal](../LICENSE) |
| 安装、卸载与开发 | [README](../README.md) |

## 提交到 awesome-dsh-plugin

将 [双语条目](xiaomao361__dsh-afterwave-style.yml) 放入目录仓库的 `data/plugins/`。仓库创建满一天且带有 `dsh-plugin` 主题标签后即可提交。具体格式见 [目录贡献指南](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/blob/main/contributing.md#adding-a-plugin--收录插件)。

## 预览素材

[鲸鱼娘立绘](../assets/whale-hero-retro.webp) 可用于介绍插件。`npm ci` 后运行 `npm run preview`，生成的 `dist/preview.html` 使用模拟数据，适合预览和截图。目录支持通过仓库根目录的 `screenshots.json` 补充截图，路径相对仓库根目录。
